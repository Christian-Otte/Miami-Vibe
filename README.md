# Palm City Paddle

A stylish Miami Vice-inspired Pong game for your browser.

## How to Start

1. Download or clone this repository.
2. Make sure `index.html`, `Background.png`, and `Startscreen.png` are in the same folder.
3. Open `index.html` in your web browser (double-click or right-click and choose "Open with").

No installation or server required!

## How to Play

- **Start Screen:**
  - Choose between Single Player (W/S) or 2 Player (W/S & O/L) mode.
  - Set the number of wins needed to win the match.
  - Click a mode button to start.

- **Controls:**
  - **Player 1:**
    - Move paddle up: `W`
    - Move paddle down: `S`
  - **Player 2 (if selected):**
    - Move paddle up: `O`
    - Move paddle down: `L`
  - **Pause/Unpause:** Press `P`
  - **Restart after win:** Press `R`

- **Objective:**
  - Be the first to reach the selected number of wins.

## Features

- Miami Vice style visuals and background
- Custom start screen with win limit selection
- Single player (vs AI) and 2 player mode
- Responsive controls and pause/restart functionality

Enjoy the game!
