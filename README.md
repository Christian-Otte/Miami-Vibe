# Miami Vibe Tic Tac Toe

A stylish Tic Tac Toe game with Miami Vibe graphics, built in HTML5 and JavaScript. Features a welcome page, username input, new game, and scores. Easily expandable for future features.

## Features
- Miami Vibe themed UI
- Welcome page with username input
- Start new game
- Score tracking
- Responsive design

## Installation
1. Download or clone this repository:
   ```
   git clone https://github.com/yourusername/TicTacPalms3.git
   ```
2. No dependencies required.

## How to Run
1. Open `index.html` in your web browser (Chrome, Edge, Firefox, etc).
2. Enter your username and click "Start New Game".
3. Play Tic Tac Toe and view scores.

## Project Structure
- `index.html` - Main HTML file
- `styles/miami.css` - Miami Vibe CSS theme
- `scripts/main.js` - Game logic
- `README.md` - Project info and instructions

## Expandability
- Add multiplayer, animations, persistent scores, or more Miami Vibe assets easily.
